# Post-parity DLC vision (Godot port)

Optional **content packs** after the base game reaches parity with legacy Unknown Horizons. A “faction” is a **player identity + building set + gfx skin**, not a separate MP diplomacy system (legacy uses [player colors](../horizons/world/player.py)).

## Parity gate (do not ship DLC gameplay before this)

| Gate | Criterion |
|------|-----------|
| **Sim** | [`PORT_CHECKLIST.md`](PORT_CHECKLIST.md) Phases 1–2 largely complete; `test_buildings.py` matrix **≥24/28**; load/save **≥6/7** (or documented SQLite subset) |
| **Playable SP** | Settlement loop + save/load + minimal warehouse/inventory UI ([`PORT_CHECKLIST_GUI.md`](PORT_CHECKLIST_GUI.md)) |
| **View shell** | `MapView`, `BuildTool`, selection wired to `CommandManager` |
| **Baseline GUT** | `./godot/run_tests.sh` green; DLC adds tests only |

**Current status:** parity **not** met — DLC pipeline and **Northern Company** pack are **scaffolding + vertical slice** (see [`PORT_CHECKLIST_DLC.md`](PORT_CHECKLIST_DLC.md)).

## Pack layout

```
content/dlc/<pack_id>/
  manifest.yaml          # IDs, building stems, gfx root
  buildings/*.yaml       # Same component shape as content/objects/buildings/

godot/resources/dlc/<pack_id>/
  buildings.json         # Generated by development/godot/export_content.py
  gfx/                   # Atlases + sprite_manifest.json (export_gfx.py)

godot/tests/dlc/         # Smoke + scenario GUT
scenes/dlc_showcase.tscn # Visual milestone (base vs DLC)
```

## ID allocation

- Base `BUILDINGS` / `RES`: from [`horizons/constants.py`](../horizons/constants.py) via export (do not hand-edit [`game_constants.gd`](scripts/autoload/game_constants.gd)).
- DLC: block **200–249** in manifest → [`dlc_constants.gd`](scripts/autoload/dlc_constants.gd) (generated).

## Art specs (isometric slice)

- **Footprint anchor:** building `position` = top-right tile ([`BuildFootprint`](scripts/sim/buildability/build_footprint.gd)).
- **Screen placement:** [`MapView.grid_to_screen`](scripts/view/map_view.gd) (PoC orthogonal; iso constants TBD in Phase 3).
- **Animations:** `idle` / `working` from producer state ([`ProductionStates`](scripts/sim/production_states.gd)); registry in [`BuildingVisualRegistry`](scripts/view/building_visual_registry.gd).

## First pack: Northern Company

- Light content: shared economy, 5 DLC building IDs, placeholder gfx, one scenario GUT.
- Showcase scene compares base lumberjack vs DLC-colored variants side by side.
